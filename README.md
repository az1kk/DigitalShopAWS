# DigitalShopAWS

**АРМ менеджера магазина цифровых товаров**

Автоматизированное рабочее место для управления продажами цифровых товаров: лицензионных ключей, подписок и программного обеспечения. Учебный проект по дисциплине «Информатика» (творческая групповая работа).

---

## Возможности

- **Авторизация** пользователя с хешированием пароля (SHA-256).
- **Каталог товаров** — управление товарами и категориями (добавление, редактирование, удаление).
- **База клиентов** — учёт покупателей с контактными данными.
- **Склад ключей** — хранение ключей активации с отслеживанием статуса (`свободен` / `зарезервирован` / `продан`). Защита от повторной выдачи одного ключа.
- **Заказы** — полный жизненный цикл: создание → оплата → выдача ключа, либо отмена с возвратом ключа на склад.
- **Статистика** — сводные показатели по каталогу, складу, заказам и выручке.
- **Аналитика** — интерактивная **3D-диаграмма продаж по месяцам** на OpenGL с вращением мышью.

## Архитектура

Проект построен по принципу слоистой архитектуры с разделением ответственности:

```
DigitalShopAWS/
├── database/      Управление подключением к БД (Singleton)
├── models/        Модели данных: Product, User, Customer, ProductKey, Order
├── repositories/  Слой доступа к данным (CRUD-операции с БД)
├── ui/            Окна и вкладки интерфейса
├── opengl/        3D-диаграмма продаж (SalesChart3D)
├── utils/         Вспомогательные классы (PasswordHasher)
└── sql/           Схема базы данных и начальные данные
```

- **Models** — простые классы данных без логики БД.
- **Repositories** — инкапсулируют все SQL-запросы; UI не работает с БД напрямую.
- **UI** — вкладки и диалоги, используют только репозитории.

## Сборка и запуск

### Требования

- Windows 10/11 (x64)
- Visual Studio 2022 с компонентом «Разработка классических приложений на C++»
- [vcpkg](https://github.com/microsoft/vcpkg) с установленным Qt 6
- Расширение Qt Visual Studio Tools

### Установка зависимостей

```bash
vcpkg install qtbase:x64-windows
```

### Сборка

1. Открыть `DigitalShopAWS.sln` в Visual Studio.
2. В **Qt VS Tools → Qt Versions** указать путь к установленной Qt из vcpkg
   (`vcpkg/installed/x64-windows/tools/Qt6`).
3. Конфигурация: **Debug** или **Release**, платформа: **x64**.
4. Собрать решение (`Ctrl+Shift+B`).
5. Запустить (`F5`).

### Вход

При первом запуске база данных создаётся автоматически с тестовыми данными.

```
Логин:  admin
Пароль: admin
```
